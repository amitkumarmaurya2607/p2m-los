# 01 - Product Context

## Why This Project Exists

Traditional loan application processes are paper-heavy, time-consuming, and require physical branch visits. FinSetu's P2M LOS digitizes the entire loan origination journey, making it accessible from anywhere.

## Problems It Solves

1. **Eliminates paperwork** - Fully digital verification and data collection
2. **Reduces processing time** - Instant validation vs. days of manual review
3. **Increases accessibility** - Available on any device with internet
4. **Improves user experience** - Clear step-by-step guidance with progress tracking
5. **Ensures data accuracy** - Real-time validation prevents errors before submission

## User Needs

- Quick and simple authentication (OTP-based, no passwords to remember)
- Clear understanding of what information is needed and why
- Ability to save progress and resume later
- Confidence that their data is secure
- Mobile-friendly experience for users without desktop access

## How It Works

### Authentication Flow

1. User enters mobile number or email
2. System sends 6-digit OTP
3. User enters OTP to verify identity
4. Redirected to onboarding dashboard

### Onboarding Flow

Users progress through 7 verification steps in sequence:

- Each step validates input before allowing progression
- Progress is visually tracked via a stepper sidebar
- Auto-save ensures no data is lost
- Users can navigate back to edit previous steps

### Verification Methods

- **PAN**: Document number validation
- **Aadhaar**: 12-digit number + OTP to linked mobile
- **Bank Account**: Micro-deposit (₹1.00) verification
- **Selfie**: Photo or short video capture via webcam

## User Experience Goals

- **Clarity**: Users always know what step they're on and what's next
- **Trust**: Professional design with security indicators
- **Speed**: Minimal fields, smart validation, instant feedback
- **Confidence**: Clear error messages and guidance throughout

## Brand Identity

- **FinSetu** - "Setu" means bridge in Hindi, bridging users to financial services
- Colors convey trust (blue-purple) and growth/prosperity (teal-green)
- Clean, modern interface with rounded elements and subtle shadows
